# Security Policy

## Reporting a vulnerability

Do not disclose credentials, API keys, private infrastructure, or an undisclosed vulnerability in a public issue.

Report sensitive findings privately to **Contact_VoidCipher@proton.me** and include only the minimum information required to reproduce the problem.

## Data handling

Round-Robin can process DNS and network metadata. Public issue reports and test fixtures must use documentation-safe example domains and address ranges rather than private production data.

## Responsible use

Use this project only against systems, domains, and networks you are authorized to investigate.
